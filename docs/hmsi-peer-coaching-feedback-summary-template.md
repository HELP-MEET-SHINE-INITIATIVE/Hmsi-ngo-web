# HMSI Peer-Coaching Feedback Summary
## Template for Program Directors

**Reporting period:** [Start date] – [End date]  
**Prepared by:** [Team lead / support owner]  
**Reviewed by:** [Program director]  
**Version:** [Number / date]  
**Status:** Draft / For review / Approved

> **Purpose:** This summary consolidates peer-coaching observations into practical program improvements. It is not an individual performance scorecard, volunteer ranking, or substitute for a confidential safeguarding, privacy, security, harassment, retaliation, or wellbeing process.

> **Privacy rule:** Report aggregate themes and process evidence only. Do not include volunteer names, individual scores, distinctive quotations, private beneficiary information, medical details, passwords, access tokens, or confidential case narratives. If a small cohort could make an individual identifiable, write **insufficient evidence for reporting** and route any sensitive matter separately.
